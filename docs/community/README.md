# 🌿 MindEase Community Module - Master Documentation

Welcome to the official specification and architectural guide for the **MindEase Community Module**.

MindEase Community is a flagship, wellbeing-first social sanctuary designed to foster safe, empathetic, and privacy-preserving human connections. Built on the principle that **healing happens through meaningful conversations and shared hobbies**, this module completely rejects dopamine-driven, addictive social media mechanics (such as likes, follower counts, and algorithmic outrage loops).

---

## 🎨 Core Design Philosophy

- **Calm & Safe**: A tranquil visual landscape with zero intrusive notifications or popularity contests.
- **Privacy-First & Anonymous**: Users interact using customizable nicknames and avatars; real identities are protected.
- **Non-Addictive Engagement**: No "Likes" or "Follower Counts". Interactions are centered around supportive reactions (❤️ Helpful, 🤝 I Relate, 🌸 Encouraged Me, 🙏 Thank You) and impact metrics (People Helped, Community Kindness Score).
- **Hobby-Driven Connection**: Four first-class Clubs (📚 Book, 🎵 Music, 📸 Photography, 🧘 Yoga) anchor community interaction around creative, reflective, and physical self-care hobbies.
- **AI-Guarded Safety**: Every post and comment passes through a multi-stage AI Safety Pipeline before public rendering.

---

## 📐 Responsive 3-Column Architecture

| Column | Component | Description |
| :--- | :--- | :--- |
| **Left Sidebar** | Primary Navigation & Clubs Hub | Sticky navigation, 4 core clubs, navigation links, compact user card (`CalmSoul21`). |
| **Center Feed** | Community Sanctuary & Discussions | Create Post card, filtering tabs, premium post cards, nested comment threads. |
| **Right Sidebar** | Wellness Widgets & Community Care | Daily Reflection, Community Care Progress, Trending Topics, Mindfulness Tips, Club Events. |

## 🎨 Dark Theme Design Tokens

- **Primary Background**: `#0B1220` (Deep Midnight Blue)
- **Secondary Surface**: `#111827` (Dark Slate)
- **Card Surface**: `#182235` (Glass Card Blue)
- **Accents**: Soft Sky Blue (`#7DD3FC`), Mint Green (`#6EE7B7`), Lavender (`#B79CFF`), Warm Beige (`#FDE68A`)
- **Card Spacing**: 20px - 24px vertical padding
- **Borders & Radii**: `rounded-3xl` (24px radius), soft ambient shadows
