# 🤝 Peer Buddy System Specification

## 1. Concept & Matchmaking

The Peer Buddy System connects users 1-on-1 for private, mutual encouragement and accountability.

### Matchmaking Criteria:
- **Shared Wellness Goals**: (e.g. Daily Meditation, Anxiety Relief, Sleep Improvement).
- **Active Times**: Matching users active around similar hours.
- **Mutual Opt-in**: Both users must explicitly opt into the Buddy System.

---

## 2. Safety & Encrypted Communication

- **End-to-End Privacy**: Buddy chats use private encryption keys.
- **Safety Boundaries**: Either user can end a buddy pairing instantly with zero friction or penalty.
- **AI Safety Guard**: Buddy chats feature real-time crisis scanning to trigger emergency help resources if self-harm signals are detected.
