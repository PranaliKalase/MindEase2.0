# 🌿 MindEase Community Module - Context & Architecture

This directory contains the feature context files for the MindEase Community Module.

For full master documentation, refer to [docs/community/README.md](file:///c:/Users/sansk/OneDrive/Documents/Desktop/MindEase2.0/MindEase2.0/docs/community/README.md).

## Key Highlights
- **Philosophy**: Safe, AI-moderated, non-addictive mental wellness social sanctuary.
- **Layout**: Responsive 3-Column layout (Left Navigation & Clubs, Center Feed, Right Wellness Sidebar).
- **Core Clubs**: 📚 Book Club, 🎵 Music Club, 📸 Photography Club, 🧘 Yoga Club.
- **Reactions**: ❤️ Helpful, 🤝 I Relate, 🌸 Encouraged Me, 🙏 Thank You (Zero Likes / Follower counts).
- **AI Pipeline**: Automatic content scan, toxicity assessment, crisis detection, and risk classification.
