# Tech Stack

## Purpose

Document the frameworks, libraries, and tools currently utilized in the MindEase2.0 codebase.

## Scope

- Frontend Frameworks
- Backend / BaaS
- Styling & Icons

## Main Content

**Frontend**
- **Framework**: React 19.x
- **Build Tool**: Vite
- **Language**: TypeScript
- **Routing**: React Router DOM (v7)
- **State Management**: React Context API

**Backend & Services**
- **BaaS (Backend as a Service)**: Supabase
- **Authentication**: `@supabase/supabase-js`
- **Database**: PostgreSQL (via Supabase)

**Styling & UI**
- **CSS Framework**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React
- **Animations**: Custom CSS keyframes and transitions (e.g., glassmorphism, particle canvas).
