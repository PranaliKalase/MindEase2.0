# Features List

## Purpose

Provide a high-level overview of the implemented features in MindEase2.0.

## Scope

- Currently Implemented Features

## Main Content

1. **Landing Page**
   - Immersive marketing introduction.
   - Cinematic intro animation, particle effects, and glassmorphism UI.
   - Explains features, mood tracking, and AI chat concepts.

2. **Authentication**
   - Secure sign-up and log-in.
   - Email/Password authentication.
   - OAuth providers (Google, GitHub).
   - Password reset functionality.

3. **Dashboard (Sanctuary)**
   - Protected user area.
   - **AI Companion UI**: Interface for chatting with an empathetic AI.
   - **Daily Journal UI**: Interface for answering guided prompts.
   - **Mood Log UI**: Interface for selecting current emotional states.
   - **Soundscape Player UI**: Interface for toggling ambient audio (432Hz).
