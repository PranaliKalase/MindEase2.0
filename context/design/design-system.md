# Design System

## Purpose

Detail the foundational design tokens and components used across the application.

## Scope

- Colors
- Typography
- Components

## Main Content

**Colors**
- **Background Void**: `#0B1026` (Deep navy/black)
- **Primary Purple Glow**: `#8A5CFF`
- **Secondary Pink/Warmth**: `#F5A5D5`
- **Soft Indigo Muted**: `#3A2E7A`
- **Highlight Lavender**: `#B79CFF`
- **Glass Elements**: `white/5` (Backgrounds) and `white/10` (Borders)

**Typography**
- Configured via Tailwind classes.
- Uses `font-serif-heading` for expressive, elegant titles (e.g., "Welcome back to your safe space").

**Core Components & Icons**
- **Icons**: Heavily utilizes `lucide-react` for minimal, consistent iconography (e.g., `Brain`, `Sparkles`, `Moon`).
- **Glass Pill**: A heavily used micro-component (e.g., `glass-pill px-4 py-1.5 border border-[#B79CFF]/30`) for displaying small stats or badges.
- **Primary Buttons**: `btn-primary` class, typically utilizing the primary purple gradient.
